# Khairat Kematian – laman semakan

Laman statik (GitHub Pages) untuk sistem Khairat Kematian Masjid.

- `index.html` – semakan awam (No. Telefon + Email).
- `kerani.html` – kemasukan data kerani (mod ujian).
- `config.js` – URL API Google Apps Script.

Data disimpan dalam Google Sheet dan diakses melalui API Apps Script. Repo ini tidak mengandungi data atau kod pelayan.
